# Bull Creek hiking map

https://saulbanov.github.io/bull-creek-hike/

A phone-friendly walking plan from Bull Creek District Park on Lakewood Drive.
Start with a color-coded 12.9-mile connected-network overview, then choose a
2.0-mile Bull Creek Loop that follows the creekside trail to its last connected
mapped point and mostly retraces; an 8.4-mile St. Edward’s Park Loop with a
1.0-mile circuit inside the park; a 5.0-mile one-way North Road Pickup route;
or a 15.5-mile Long Loop with side excursions and retracing. The 12.9-mile
network inventory is not a continuous through-hike. Distances are approximate.

Includes possible creek-crossing pins, mile markers, GPX downloads, optional device
location, topo and satellite basemaps, and links to current trail status, weather and
the USGS gauge. Location remains in the visitor’s browser and is not recorded by this page.
Map tile requests go to the selected basemap provider.

The crossing pins are inferred from City trail / OpenStreetMap creek intersections.
The Long Loop adds a third candidate on a St. Edward's branch and revisits some pins.
They are not field-verified fords, bridge locations, or a statement about current passage.
No ford-depth or flow threshold has been established. Minor gullies and tributaries have
not been inventoried. Check signs and conditions on the ground.

The Bull Creek Loop stops before a roughly 9.2-meter break in the City trail
line; the next mapped segment is not assumed passable. The north-road route
requires a pickup at a City-mapped access point that has not been checked for
a safe waiting area.

`route-data.json` carries source IDs, dates, hashes, geometry and method. The GPX files are
calculated routes, not GPS recordings. Forest Ridge access status was checked October 21,
2026 and does not update automatically. The map is static; raster basemaps need a connection.
Built-in vector graphics show each route when tiles cannot load.

Trail geometry: City of Austin / Austin Water, captured September 29, 2026.
Creek geometry: © OpenStreetMap contributors, ODbL, captured September 28, 2026.
Leaflet 1.9.4 is bundled under its BSD-2-Clause license in `vendor/LICENSE`.
Basemap attribution appears on the map. Do not infer a license for agency data from
Leaflet’s license.

The source builder is maintained in the private Austin outdoors project. This repository
contains only the generated public site. GitHub Pages serves the root of `main`.
